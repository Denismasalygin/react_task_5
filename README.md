Описание проекта
React-приложение с несколькими страницами, получением данных из API, интерактивными картами, фильтрацией, сортировкой и корзиной покупок.
В проекте реализованы работа с REST API с помощью RTK Query, кеширование запросов, ленивая пагинация, Redux для управления состоянием корзины и сохранение корзины в localStorage.

Функциональность
Главная страница
Главная страница с отдельным визуальным оформлением.
Три информационных элемента с изображениями, расположенных в общем блоке.

Контакты
Получение данных пользователей из API DummyJSON.
Отображение 10 элементов с информацией о пользователях.
Отображение местоположений на Яндекс Картах с помощью маркеров.
Поиск и фильтрация элементов.
Сортировка и фильтрация могут применяться одновременно.

Магазин
Отображение участков в виде карточек.
Фильтрация участков по городу.
Сортировка по цене по возрастанию и убыванию, а также возможность отключить сортировку.
Отображение местоположений участков на Яндекс Картах.
Ленивая пагинация: при прокрутке страницы автоматически загружаются следующие 10 элементов.
Автоматическое обновление маркеров карты по мере загрузки новых элементов.
Открытие модального окна с подробной информацией об участке при нажатии на карточку или маркер на карте.
Добавление участков в корзину и удаление из неё.

Корзина
Отображение добавленных участков.
Отображение количества товаров в корзине в шапке сайта.
Удаление отдельных элементов и очистка всей корзины.
Подсчёт общей стоимости участков.
Сортировка и фильтрация участков по городу.
Отображение участков на Яндекс Картах с возможностью открыть модальное окно по нажатию на маркер.
Состояние корзины хранится в Redux и сохраняется в localStorage, поэтому добавленные элементы остаются после перезагрузки страницы в том же браузере.

Используемые технологии и зависимости

Основные технологии
React — создание пользовательского интерфейса.
JavaScript (JSX) — логика приложения и описание компонентов.
Webpack — сборка проекта.
React Router DOM — маршрутизация между страницами.
Redux Toolkit — управление состоянием приложения.
React Redux — подключение Redux к React-компонентам.
RTK Query — получение данных из API, кеширование запросов и управление состоянием загрузки.
SCSS / CSS Modules — стилизация компонентов и изоляция CSS-классов.
Yandex Maps API — отображение интерактивных карт и маркеров.
DummyJSON — внешний API для получения данных пользователей.
clsx — условное объединение CSS-классов.

Список установленных пакетов и их версий находится в package.json. Для установки зависимостей используется npm.

Переиспользуемые компоненты
Компоненты, которые используются на нескольких страницах, вынесены в директорию src/components/.
Header — шапка сайта с навигацией между страницами и количеством элементов в корзине.
Loader — индикатор загрузки данных и карты.
PlotCard — карточка участка, используемая в магазине и корзине.
PlotModal — модальное окно с расширенной информацией об участке и анимацией открытия.
PlotMap — компонент Яндекс Карты с маркерами участков и обработкой нажатий на них.
ShopControls — панель управления с сортировкой, фильтрацией по городу, переключением карты и кнопкой очистки корзины.
SortButton — кнопка циклической сортировки с тремя состояниями: по возрастанию, по убыванию и без сортировки. Иконка зависит от текущего состояния.
CityFilter — фильтр участков по городу.
Tooltip — общая кастомная подсказка при наведении на элементы интерфейса.

Работа с API и кеширование
Для получения данных используется DummyJSON, а запросы организованы с помощью RTK Query.
RTK Query кеширует полученные данные. При повторном посещении страницы в течение минуты кешированные данные могут использоваться повторно без нового запроса.
Для магазина реализована ленивая пагинация: новые данные загружаются по мере прокрутки страницы, по 10 элементов за запрос.

Изображения и иконки
Изображения для карточек были взяты из макета в Figma, поскольку изображения не приходили в ответах API. Поэтому в карточках магазина используются подготовленные локальные изображения, которые циклически чередуются между элементами.
Большинство иконок взято из макета Figma. Для кнопок сортировки используются отдельные иконки.

Установка и запуск
Требования
Установленный Node.js v24.

Менеджер пакетов npm.
Git — для клонирования репозитория.
1. Клонирование репозитория
git clone <URL_ВАШЕГО_GITHUB_РЕПОЗИТОРИЯ>

Перейдите в папку проекта:
cd <ИМЯ_ПАПКИ_ПРОЕКТА>
Вместо значений в угловых скобках укажите URL своего репозитория и имя его папки.

2. Установка зависимостей
npm install

3. Запуск в режиме разработки
npm start

4. Сборка проекта
npm run build
После успешной сборки готовые файлы будут помещены в директорию, указанную в конфигурации Webpack.
